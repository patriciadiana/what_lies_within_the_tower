# What Lies Within the Tower

**"What Lies Within the Tower”** is a puzzle-adventure video game set in a medieval city where the main character finds himself curios about that mysterious tower in the centre of the city. A series of puzzles and challenges await to be solved and mysteries to be discovered. The setting is dark and mysterious, its purpose being to maintain the enigmatic style of the game.

The repository of the video game can be found [here](https://github.com/patriciadiana/what_lies_within_the_tower).

The game was developed in **Unity** (both 2D and 3D) using **C#** for scripting. For some of the elements in the scenes **Blender** was used for 3D modelling.

## Preconditions

### Install Git
To install and run the game, you need to install [Git](https://git-scm.com/downloads).

## Installer

1. Open **Git Bash** terminal and run the following command to clone the repository:
```bash
git clone https://github.com/patriciadiana/what_lies_within_the_tower
```
2. After cloning is complete, open the folder
> what_lies_within_the_tower\Installer
3. Inside the folder, double-click on: 
> WhatLiesWithinTheTower.exe
4. Follow the instructions in the setup wizard to install the game.
5. Once the installation is finished, you can launch the game:
   * From the Desktop, if you selected to create a shortcut during installation, or
   * By searching for "WhatLiesWithinTheTower" in your system's search bar.
